# 💰 Personal Expense Tracker

## 📌 Project Description

The Personal Expense Tracker is a simple Python-based project designed to record and calculate daily expenses.

## 🎯 Purpose

The purpose of this project is to help users keep track of their spending in a simple and organized way.

## ✨ Features

- Enter expense amounts
- Store expenses using a Python list
- Calculate total expenses
- Sample expense data
- Simple project website
- Markdown documentation
- GitHub Pages deployment

## 🛠️ Technologies Used

- Python
- HTML
- CSV
- Markdown
- GitHub
- GitHub Pages
