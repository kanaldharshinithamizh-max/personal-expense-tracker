# User Guide

## How to Run the Python Program

1. Open the file `expense_tracker.py`.
2. Run the Python program.
3. Enter the number of expenses.
4. Enter each expense amount.
5. The program displays the total expense.

## Example

If the expenses are:

- ₹100
- ₹200
- ₹300

The total expense will be:

₹600
