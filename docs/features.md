# Features

## 1. Enter Expenses

The user can enter the number of expenses and their amounts.

## 2. Store Expenses

The Python program stores the expenses in a list.

## 3. Calculate Total

The program calculates the total expense using the sum() function.

## 4. Simple Interface

The program is simple and easy to understand.

## 5. Website

The project includes a simple HTML website.

## 6. GitHub Pages

The website can be published using GitHub Pages.
